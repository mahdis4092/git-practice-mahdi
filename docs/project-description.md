# Project Description

## Overview

This project is a Git and GitHub practical assignment using Python.

The project demonstrates how Git can be used to track changes in a software project.

## Features

The calculator currently supports:

* Addition
* Subtraction
* Multiplication

## Git Features Practiced

This project demonstrates:

* Git repository initialization
* Git staging
* Git commits
* Git branches
* Branch merging
* GitHub remote repository
* Pushing to GitHub
* `.gitignore`

## Project Structure

The source code is stored in the `src` directory and project documentation is stored in the `docs` directory.
